\section*{Preamble}

{
\justifying

The \OldVersionNumber\ version of the Company/Facility Directory (C/FD) is designed to assist those who like driving in old American Truck Simulator versions without the help of simulated GPS navigation.

Versions of the directory for newer game versions are available, too.
Further information is available from the discussion thread on the SCS forum and from the GitHub repository:

\url{https://forum.scssoft.com/viewtopic.php?t=317942} \par
\centering \vspace{1ex}
\url{https://github.com/nautofon/cfd} \par
