\section*{Preamble}

{
\justifying

The 1.49 version of the Company/Facility Directory (C/FD) is designed to assist those who like driving in old American Truck Simulator versions without the help of simulated GPS navigation.
A version of this directory for newer game versions is available separately.

The final edition of the C/FD may look very different from this early preview.
Future updates will be made available on the SCS forum.
Should you find this project interesting, please join the discussion!
